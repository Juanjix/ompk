# PHASE 03 — Logo & Visual Identity, v0.3 (FINAL — Phase 03 closed)

Status: direction approved, pending vector production and physical test. **Name: OMPK** (supersedes Orson, see `docs/naming-round-03.md`). Legal/domain clearance is next — see `docs/legal-domain-clearance.md`.

## 00 — Decision history, briefly

1. v0.1 tested four wordmark directions for "Orson," recommended the Ring-O grotesk.
2. v0.2 swapped the name to OMPK (the founder's son's initials) in the same system; added a 2×2 grid monogram seal as a secondary crest for hardware/leather.
3. **v0.3 — approved.** A bold, connected script (instrument-headstock energy, in the spirit of a Rickenbacker logo without tracing it) was tested against the Ring-O grotesk. The founder chose the **script as the primary wordmark**. This is a deliberate, logged departure from Brand Bible §11's original "should not look vintage" rule — reasoning captured there and in §02 below.

## 01 — Final system

- **Primary wordmark**: OMPK in a bold, connected script. Production placeholder: Yellowtail (Google Fonts) — stand-in only; commission or hand-draw a custom script before launch so the mark isn't built on a stock typeface. Used on: hang tags, back-of-jacket print, woven patches, campaign posters, Instagram, packaging.
- **Functional fallback**: plain-set "OMPK" in Archivo, for sizes/contexts where the script loses legibility — favicon, browser tab, fine print, anywhere the script would blur into noise. Utility only, never presented as a second brand mark.
- **Secondary mark — monogram seal**: 2×2 grid (O M / P K), block-lettered, ring device on the O quadrant carried over from the earlier grotesk exploration. Reserved for hardware, leather emboss, interior collar stamps — contexts where a script would lose definition when embossed or engraved at small scale.
- **Location lockup**: OMPK (script) / BUENOS AIRES (small caps, grotesk, for contrast)
- **Archive lockup**: OMPK (script) / BUENOS AIRES / ARGENTINA · EST. 2026
- **Catalog system**: OMPK (script) / CAT. Nº 001 / BUENOS AIRES

Visual references: [OMPK Script Test](https://claude.ai/code/artifact/d87ab6f9-12af-4ae2-bb93-76b0e9c1da2f) (final direction, script vs. grotesk comparison, applied contexts) and [OMPK Monogram](https://claude.ai/code/artifact/3a3b0123-d9c0-4ad7-8e76-dfd31da271da) (the secondary seal, unchanged by this decision). The v0.1 Orson artifact remains published for historical reference only.

## 02 — Why the script, on the record

The grotesk Ring-O was the "safe" choice per §11 as originally written — correct, reproducible, indistinguishable from a dozen other contemporary labels. The script does something the grotesk couldn't: it puts the brand's music-culture DNA (§07, rock culture as 20% of the visual formula) directly into the one asset used everywhere, the same logic that made the Ring-O device worth doing in the first place — one deliberate break in an otherwise disciplined system (§10, Order + Chaos), just moved from a single letter to the whole mark.

The traded-off risk — reading as costume or vintage pastiche — is real and was flagged before the decision was made. It's managed structurally, not by hedging the logo: everything *surrounding* the wordmark (photography per §15–16, casting, product silhouette per §21, copy per §27–28) stays contemporary, so the one vintage-coded element in the whole identity is the signature itself, the way a musician's actual signature can look however it looks without the rest of the room looking like 1974.

## 03 — Color versions

Unchanged from v0.2, per §14 (never more than Paper + Ink + one signal color): Ink on Paper (default), Paper on Ink (reversed), Paper on Signal Red (campaign/limited use only).

## 04 — Clearspace & minimum size

- Script wordmark: clearspace on all sides equal to the cap-height of the "O". Print minimum ~20mm wide (scripts need more room than grotesk to stay legible) — below that, switch to the Archivo functional fallback, not a shrunken script.
- Monogram seal: minimum ~10mm for hardware/leather embossing, per v0.2.

## 05 — Applied contexts checked

- Back-of-jacket print, woven patch, campaign poster — script (see OMPK Script Test artifact)
- Leather emboss, storefront signage reversed — monogram seal (see OMPK Monogram artifact; storefront signage should be revisited with the script once produciton-vectored, since v0.2's storefront test used the grid seal, not the script)
- Waistband embroidery, Instagram avatar, hang tag — tested with the earlier grotesk in v0.1/v0.2; **re-test with the script before treating these as settled**, since a connected script behaves differently in thread and at circle-crop scale than a grotesk does.

## Open items before this is production-ready

- **Commission or hand-draw the actual script** — Yellowtail is a stand-in for direction review, not a logo the brand should ship on. This is the single most important open item.
- Re-test the script specifically at waistband-embroidery and Instagram-avatar scale (flagged above) — not yet confirmed the way the grotesk was.
- Vector the monogram seal properly; it is unaffected by this decision but still not production artwork.
- Whenever it becomes relevant: decide publicly or keep private the OMPK-as-family-initials origin story (unchanged open item from v0.2).
